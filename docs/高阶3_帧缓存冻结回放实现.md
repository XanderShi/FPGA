# 高阶挑战 3：帧缓存、冻结与 100 帧回放

## 显示模式

| 模式 | 左半屏 | 右半屏 |
|---|---|---|
| 实时（默认） | 整屏 Canny 二值边缘 | 整屏 Canny 二值边缘 |
| 冻结 | 实时彩色图像 + 红色边缘 | 按键时刻的中值灰度图 |
| 回放 | 实时彩色图像 + 红色边缘 | 选定历史帧的中值灰度图 |

实时模式保留目标框和中文标签。冻结/回放模式把目标框和标签叠加在右侧
历史画面上；坐标按 2×2 缩小后的图像位置转换。

左右比较画面都来自 DDR 中的完整 `1280×720` 帧。显示读模块按扫描顺序
做 2×2 抽样，得到两个 `640×360` 图像，并在 1280×720 屏幕上左右排列，
上下保留黑边以维持 16:9 比例。

## 按键

| 操作 | 功能 |
|---|---|
| K1 短按 | 实时/冻结模式阈值 −8；回放模式上一帧 |
| K2 短按 | 实时/冻结模式阈值 +8；回放模式下一帧 |
| K1 长按 0.8 s | 冻结/解除冻结；回放模式返回实时 |
| K2 长按 0.8 s | 进入/退出 100 帧回放 |

短按在松开时确认，长按只触发一次，因此长按冻结不会附带一次阈值加减。
按键具有两级同步和 20 ms 消抖。

## DDR 布局

历史环使用 100 个 4 MiB 对齐帧槽，另有槽 100/101 作为冻结/回放期间的
实时画面双缓冲。

每个帧槽内：

| 偏移 | 内容 |
|---|---|
| `0x000000` | 1280×720 个 16 bit `{RGB555, edge}` |
| `0x200000` | 1280×720 个 16 bit `{8'h00, median_gray}` |

总地址范围约 408 MiB。按摄像头 30 fps，100 帧历史约为 3.33 秒。

正常实时模式下，100 个历史槽循环覆盖。冻结或回放期间，历史环暂停推进，
新帧写入槽 100/101 以维持左侧实时画面，因此右侧冻结/回放帧不会被覆盖。

## 关键实现

- `src/rgb_align_ring.v` 同时对齐原始 RGB 和中值灰度。
- `src/frame_ring_ctrl.v` 负责双平面 AXI 写入、100 槽回绕、冻结保护和
  双源显示读取。
- `src/sobel_ctrl.v` 负责阈值、短按/长按仲裁以及实时/冻结/回放状态。
- 顶层按帧保存目标识别框和标签，冻结/回放时使用对应物理槽的元数据。

## 写侧数据完整性

摄像头逐像素写入 W0 FIFO，DDR 写控制器必须等 FIFO 内已有完整
`W_BURST=128` 个 128 bit 数据包后再启动一次 AXI 写突发。不能在 FIFO
仅有 1 个数据包时提前启动，也不能在突发中途 FIFO 已空时继续推进地址；
否则 burst 后半段会写入重复/无效数据。

每个帧槽的 raw 和 median 平面都严格写满 `1280×720×2 = 1,843,200`
字节后才发布该帧。完整帧写流回归会逐字比较 DDR 模型中的 raw/median
数据，而不是只检查地址指针是否到达帧尾。

## 回归测试

- `sim/tb_sobel_ctrl.v`：短按阈值、长按冻结、回放翻帧。
- `sim/tb_frame_ring_ctrl.v`：双平面写入、槽回绕、冻结保护。
- `sim/tb_frame_ring_read.v`：左实时 raw、右历史 median 的扫描读取顺序。
- `sim/tb_frame_e2e.v`：已知帧经过 AXI 写入模型后逐像素读回比对。
- `sim/tb_frame_write_stream.v`：按摄像头逐时钟供数，覆盖 128 拍写突发；
  默认小高度回归，可以 `-G V=720` 跑完整 1280×720 帧。
- `sim/tb_frame_burst32.v`：32 拍 DDR 读突发、ARLEN 和跨行地址。
- `sim/tb_edge_system.v`：RGB/Canny/Sobel、目标识别与像素对齐链路。
